# Report Format

## PDF

- Cover page
- Project name and domain
- Scan date
- Executive summary
- Overall risk score
- Asset summary
- Findings summary by severity
- Top risks
- Detailed findings
- Recommendations
- Appendix with assets and scan metadata
- Authorized-use disclaimer

## Excel

Sheets:

- Summary
- Assets
- Findings
- Open Ports
- Security Headers
- SSL/TLS
- Technologies
- Changes
- Scan Metadata
